================================================================================
                        LOG STORAGE & CLEANUP
================================================================================

Will Logs Fill Memory?
- Logs are stored on DISK (/mosquitto/log/mosquitto.log), not in RAM
- Your 8 GB disk has plenty of space for months of logs
- Each MQTT message = ~100-500 bytes of log data
- Even with 1000 messages/day = ~0.5 MB/day = ~15 MB/month

Safe Limit: You can store 500+ MB of logs before worrying

Auto-Rotation (Optional - Setup Later):
If logs get huge (>500 MB), you can enable log rotation in mosquitto.conf:
  log_dest file /mosquitto/log/mosquitto.log
  max_log_size 100000  # Rotate at 100MB

Manual Cleanup (if needed):
# Clear all logs:
docker exec cs-mqtt truncate -s 0 /mosquitto/log/mosquitto.log

# View log file size:
docker exec cs-mqtt du -h /mosquitto/log/mosquitto.log

Recommendation:
- Keep logs running for debugging
- Check size monthly: docker exec cs-mqtt du -h /mosquitto/log/
- Clean only if > 500 MB (unlikely for small deployments)

================================================================================
                        LESSONS LEARNED
================================================================================

1. Auto Reconnect Issue
   - MQTTX "Auto Reconnect" ON = constant reconnections
   - Each reconnect creates new session, kicks out old one
   - Fix: Always disable Auto Reconnect for stable testing

2. Certificate Verification
   - Self-signed certs don't match IP addresses
   - "SSL Secure: OFF" bypasses this validation
   - Data is still encrypted (just verification skipped)
   - For production: Use CA-signed cert or match IP in cert

3. Security Group Rules
   - MQTT ports must be explicitly added (not just SSH/HTTP/HTTPS)
   - Port 1883 (unencrypted) and 8883 (TLS) both needed
   - Source 0.0.0.0/0 allows all IPs (can be restricted later)

4. Client ID Management
   - MQTT only allows ONE connection per (username, Client ID) pair
   - Multiple gateways: Same username, DIFFERENT Client IDs
   - Changing Client ID allows multiple concurrent connections
